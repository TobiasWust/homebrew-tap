# homebrew-tap

Homebrew casks by [wust](https://wust.dev).

```bash
brew install --cask tobiaswust/tap/fnlockbar
```

| Cask | App |
| --- | --- |
| `fnlockbar` | [FnLockBar](https://github.com/TobiasWust/FnLockBar) – menu bar indicator and per-app switcher for the fn key mode |

Casks are updated automatically when a new release is published.
